🥋 About the Ultimate Fight Fan-Service Project 🥊

Welcome to the ultimate resource for every **UFC** enthusiast! This platform is dedicated to providing fans with real-time, comprehensive information about fighters, upcoming events, and historical results.

Our Mission

Our goal is to be the most reliable and engaging source for UFC data. This project serves as a showcase for modern Angular techniques, including **Standalone Components**, **Server-Side Filtering**, and **RxJS Debouncing**.

Core Technical Requirements

  • **Architecture:** Fully **Standalone Component** model (Angular 20+).
  • **Routing:** Five required routes, including dynamic parameter routing.
  • **Data:** All data access handled via a central `ItemsService` using `HttpClient`.
  • **Interaction:** Clear separation of concerns using `@Input()` and `@Output()`.
